# Paper 1 source

LaTeX source for *AgentSafetyRecord and SafeOrderBench: State-Verified Safety
Evaluation for Transactional AI Agents*, version 0.7 (banking-only
black-box release and black-box pilot with judges).

```text
paper/
├── main.tex                          Manuscript (single file, inline bibliography)
├── figures/
│   └── architecture.png              Figure 1 (regenerate: scripts/build_architecture_figure.py)
└── build/                            Local build output (not committed)
```

## Build

Any TeX Live 2023+ distribution works:

```bash
cd paper
pdflatex main.tex && pdflatex main.tex
```

The bibliography is inline (`thebibliography`), so no BibTeX pass or `.bbl`
file is needed. Figure 1 is generated by
`python scripts/build_architecture_figure.py` (requires `matplotlib`).

## What the numbers rest on

- The released black-box demonstration (Section on black-box execution) is
  regenerated deterministically from the repo root:

  ```bash
  python -m agentsafetyrecord run --domain banking --agent session-reference
  python -m agentsafetyrecord run --domain banking --agent session-unsafe
  pytest
  ```

- The black-box pilot (two agents under test — `claude-opus-5-5`
  and `gpt-6-luna` — claim extractor, two judges including
  `gpt-6.2-sol`) was run with `scripts/run_blackbox_pilot.py`; its
  artifacts are preserved in `artifacts/pilot/blackbox_v3/` (runs,
  judgements, labeling sheets, `manifest.json`, `analysis.json`), with
  a copy of the analysis at `paper/results/pilot_v3.json`. Hosted models sample
  non-deterministically, so a re-run will not reproduce it exactly.

## Human labeling (done)

The pilot sheets have been hand-labeled by two annotators
(`claims.csv`/`replies.csv`/`runs.csv` plus `*_second.csv` in
`artifacts/pilot/blackbox_v3/labels/`, exported from the Annotator1/2
workbooks) and the manuscript reports the resulting statistics:
extraction accuracy 94/94, verdict accuracy 94/94, no missed claims in
92 replies, human–deterministic agreement 64/64, inter-annotator
κ = 1.0. Recompute any time with:

```bash
python scripts/pilot_analyze.py --pilot-dir artifacts/pilot/blackbox_v3
```
